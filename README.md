# gis-scripts
Small PyQGIS scripts that automate GIS data checks.

- layer_inventory.py: lists every vector layer in a QGIS project with geometry type, CRS, feature count and fields.
- unique_values.py: lists the different values found in each column.

Tested with QGIS 4.2.
Sample data: NORDHAVEN, a demonstration dataset for Bremen built from OpenStreetMap-derived data.
